# SpiritLlama Desktop Changelog

## Alpha v1.1.110 (2026-11-26)
- Initial public Windows x64 Desktop release (`SpiritLlama-Alpha-v1.1.110+20261125-2145-75c50fc`).
- Self-contained `.NET 9` WPF + WebView2 host with bundled Vulkan `llama-server.exe` runtime (`engine\`).
- Packaged standalone path isolation (`%LocalAppData%\SpiritLlama` for installed setups, local directory for `portable.mode`).
- Includes CodexSpaces & FinTrader Analytics Lab (live yFinance telemetry, USD/ZAR conversion, interactive strategy overlays, `Market Signals Analysis Node`, and two-tab `Execute | Risk Rules` Discipline Gate), Canvas IDE, Terminal, and Live Preview Browser automation.
